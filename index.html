About Me

Who am I?

I'm Manish Sahu, a Flutter Developer based in Raipur, Chhattisgarh, India, with 2.5+ years of experience in developing and maintaining cross-platform mobile applications using Flutter and Dart for Android and iOS.

Currently, I work at FixingDots, where I contribute to FixHR Or Teams (Liugong), an employee management application. My responsibilities include developing responsive and reusable UI components, implementing state management using BLoC and Freezed, integrating REST APIs using Dio, and working with Socket.IO, Firebase services, real-time GPS tracking, and Google Maps. I also handle production issue resolution, performance improvements, and Android and iOS app releases.

Previously, I worked at RiverHouse Technology on Collegiate Backer, a crowdfunding platform, where I developed reusable Flutter components and integrated Firebase Authentication, Cloud Firestore, Firebase Storage, REST APIs, and Stripe payment functionality.

I also developed Appixo, a room-rental search application using Flutter, GetX, and Firebase.

My technical strengths include Flutter, Dart, state management, API integration, responsive UI development, Clean Architecture, and application deployment. I focus on writing clean, maintainable, and scalable code while delivering reliable mobile applications and continuously improving my technical skills.
